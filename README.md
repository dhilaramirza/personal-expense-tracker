# 💰 Personal Expense Tracker

An interactive expense tracking dashboard built using Python, Streamlit, Pandas, and Plotly to analyze spending patterns and monitor monthly budgets.

🚀 **Live Demo:** https://dhilara-spending-insights.streamlit.app/

💻 **GitHub Repository:** https://github.com/dhilaramirza/personal-expense-tracker

## ✨ Features
- Interactive expense dashboard and visualizations
- Category-wise and payment method analysis
- Date range filters and transaction search
- Monthly budget tracking and expense insights
- Add expenses and download transaction data as CSV

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
